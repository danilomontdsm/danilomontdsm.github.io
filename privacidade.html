Política de Privacidade do dannexplica

Última atualização: 24 de novembro de 2026.

1. O que o aplicativo faz

O dannexplica sincroniza uma pasta do computador do usuário com uma pasta do Google Drive do próprio usuário.

2. Dados acessados

Com a autorização do usuário, o aplicativo acessa o Google Drive da Conta do Google autorizada para listar, enviar, baixar e atualizar os arquivos da pasta sincronizada. O aplicativo também guarda no computador do usuário o token de autorização fornecido pelo Google, para não pedir login a cada uso.

3. Como os dados são tratados

  • Os arquivos trafegam diretamente entre o computador do usuário e o Google Drive.
  • O desenvolvedor não recebe, não armazena e não tem acesso aos arquivos ou aos dados da Conta do Google do usuário.
  • Os dados não são vendidos, compartilhados com terceiros, usados para publicidade nem usados para treinar modelos de inteligência artificial.

4. Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google pelo dannexplica seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Revogar o acesso

O usuário pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions e apagar o token guardado removendo o aplicativo do computador.
